DESIGN PRINCIPLES

Boring navigation is good navigation

Good web navigation is clear, precise, familiar and consistent. It is not the place to be creative. The menu above is in the same position, the same order, and the same style on all four pages, and the logo in the top-left corner returns you home from anywhere.

Read the full rationale

Visual hierarchy

Larger, higher elements read as more important. The type scale steps in fixed ratios so headings never compete.

Negative space

Unmarked space between elements reduces overload and pushes the eye toward the call to action.

Contrast

Near-black text on white clears WCAG AA comfortably, so body copy stays legible on a phone in daylight.

Above the fold

The offer, the value proposition and the primary CTA are all visible before any scrolling happens.
