ABOUT THIS SITE

Why it looks the way it does

Each choice below traces back to a principle from the course material.

A blue palette

Blue reads as trust and calm, and it stays distinguishable for visitors with red-green color blindness — the same reasoning behind Facebook's branding. The palette is monochromatic blue plus one warm accent reserved for calls to action, so the action is never ambiguous.

Sans-serif type

Body and headings use the Arial/Helvetica family. Serif faces earn their tails in print, where characters are solid; on screen those tails blur. Italics and all-caps body text are avoided — capitals cut readability by roughly ten percent and read as shouting.

Underlined links

In-text links are a different color and underlined; visited links shift color so you remember where you have been. Nothing else on the site is underlined, because an underline that is not a link is a broken promise.

Few choices per page

Hick's Law: decision time climbs as options multiply. The global menu holds four items and each page carries one primary action, so a visitor never stalls in front of a wall of equal-weight buttons.

Boring navigation

The menu is in the same position, order and style on all four pages, and the logo in the top-left corner returns you home from anywhere. Navigation is the wrong place to be creative.

A print stylesheet

Printers chop anything wider than about 600–750 pixels. Printing any page here drops the navigation and footer and reflows the content to a 750-pixel column, so a printed copy is not a wall of clipped lines.
