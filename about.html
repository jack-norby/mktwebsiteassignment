Why this site looks the way it does

Each choice traces back to a principle from the course material.

A blue palette

Blue reads as trust and stays distinguishable for visitors with red-green colour blindness. One warm accent is reserved for calls to action, so the action is never ambiguous.

Sans-serif type

The Arial and Helvetica family throughout. Serif tails help in print but blur on screen. Italics and all-caps body text are avoided, since capitals cut readability.

Underlined links

In-text links are a different colour and underlined, and visited links shift colour. Nothing else is underlined, because an underline that is not a link is a broken promise.

Few choices per page

Hick's Law: decision time climbs as options multiply. The menu holds four items and each page carries one primary action.

Sticky side content

News, offers and site information sit in a rail beside the main content, so they stay reachable without interrupting the reading column.

A print stylesheet

Printers chop anything wider than about 750 pixels, so printing drops the navigation and side columns and reflows the content to fit a sheet of paper.
